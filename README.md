# 📊 Sales Performance Dashboard - Power BI

## 🔹 Project Overview
This project is an interactive Sales Performance Dashboard created using Microsoft Power BI.  
It helps analyze business performance through key metrics such as revenue, profit, growth trends, and regional performance.

## 🔹 Objectives
- Track overall sales performance  
- Identify top-performing products and regions  
- Monitor monthly and yearly growth  
- Support data-driven business decisions  

## 🔹 Tools & Technologies
- Microsoft Power BI  
- Excel / CSV Dataset  
- Data Cleaning & Modeling  
- DAX Measures  

## 🔹 Key Features
- Dynamic KPI cards (Revenue, Profit, Quantity)  
- Sales by Region & Category  
- Monthly Trend Analysis  
- Interactive filters & slicers  
- Clean and professional UI

## 🔹 Dataset
The dataset contains:
- Order ID  
- Product Category  
- Sales Amount  
- Profit  
- Region  
- Date  

## 🔹 Business Insights
- Helps managers identify weak regions  
- Supports inventory planning  
- Improves strategic sales decisions  

## 🔹 How to Use
1. Download `.pbix` file  
2. Open in Power BI Desktop  
3. Refresh data  
4. Explore using filters
